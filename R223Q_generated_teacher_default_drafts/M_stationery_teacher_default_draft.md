## 一、课时定位

本课处在《我为文具代言》单元后段，学生已经经历了文具观察、文具故事和结构探究，本节课要把“文具结构服务使用”的认识转化为真实改造。课堂重心不再是长时间讲解，而是让学生带着一个小问题进入设计、尝试、调整、展示。

## 二、教学目标

1. 能从文具结构和使用问题出发，说出一个想改进的小麻烦。
2. 能尝试用粘土、线材、纸材等材料完成一次文具小改造，并说明材料选择理由。
3. 能在制作过程中根据教师和同伴反馈调整作品，保留过程证据。
4. 能用“原来……我用了……现在可以……”介绍自己的文具新朋友。

## 三、教学过程

### （一）回到结构：文具为什么这样设计

教师先用毛笔工序图和身边文具小结构唤醒学生已有经验，追问：“这个小地方让文具哪里更好用？”如果学生只说“好看”，教师把问题拉回使用：更好握、更好找、更好收，还是更安全？

本环节只留下一个证据：学生能说出一个文具结构和一个使用作用。确认这一点后，课堂进入设计任务。

### （二）像设计师一样想：一个小问题，一个小办法

教师出示几个带小巧思的文具细节，引导学生发现“设计不是做得越复杂越好，而是发现一个小麻烦，再想一个小办法”。学生在学习单上写下自己要解决的问题，例如“铅笔容易滚”“笔不好找”“握起来不舒服”。

如果学生想法太大，教师帮助他们缩小为一个位置、一个材料、一个目标。

### （三）1+1 合作小设计

教师给出低门槛挑战：“一支铅笔加一块粘土，能不能让它更好用或更有趣？”学生同桌合作，一人固定文具，一人塑形，一人说理由。

学生常会先做小动物、小花或名字牌。教师不急着否定，而是追问：“它让文具更好看，还是更好用？如果是更好找，你能说出谁会需要它吗？”中途投屏两件半成品，一件只是装饰，一件解决了防滚或标记问题，让学生比较。

本环节至少留下 1 张小设计照片和一句改进理由。

### （四）1+n 文具大变身

学生带着 1+1 的经验进入正式创作。教师提供线材、纸材、形状材料和少量连接方法，但提醒学生：“材料不是越多越好，只留下能帮你解决问题的材料。”

教师巡视时重点看三点：材料是否服务问题，结构是否影响使用，合作是否均衡。若学生堆材料，教师问：“如果只能留下一个材料，你留哪个？它帮了你什么？”若学生不会固定，教师用半成品示范盘、绕、包、贴等局部方法。

过程证据包括材料选择理由、作品局部照片和一次调整说明。

### （五）笔友汇与赠笔礼

作品完成后，学生把文具新朋友放到展示区，用句式介绍：“我的新朋友原来……我用了……现在可以……”同伴评价不能只说好看，要从结构、功能、材料、使用四个词里选一个角度。

最后进行赠笔礼。教师提醒学生说出为什么送、希望对方怎样使用。赠笔语和使用建议将进入后续《购买文具建议书》和《文具课堂使用指南》的素材池。

## 四、评价证据

| 证据 | 用途 |
| --- | --- |
| 小麻烦记录 | 判断学生是否从使用问题出发 |
| 1+1 照片和理由 | 判断低门槛尝试是否成立 |
| 1+n 作品和过程记录 | 判断材料是否服务问题 |
| 展示语和赠笔语 | 判断表达能否连接单元表现性任务 |
