## 一、课时定位

本课是纸印学习中的材料与技法准备课。学生要从“纸可以做造型”转向“纸材、肌理和印法会留下不同印痕”。课堂需要观察、试验和小幅作品，但不应扩成过重的大创作。

## 二、教学目标

1. 能观察纸材厚薄、软硬、粗糙、光滑和凹凸肌理，预测可能留下的印痕。
2. 能用揉、撕、折、拼贴等方法制造纸的新肌理，并完成一次小块试印。
3. 能比较不同印法带来的清楚、模糊、灰层、边缘等效果。
4. 能带着试印记录介绍自己的纸印作品。

## 三、教学过程

### （一）走进版画车间：先发现印痕

教师出示普通绘画作品和纸印作品，请学生找一找哪一张更像“印”出来的。学生如果只说“好看”，教师放大局部边缘，引导他们看重复、压印、留白和肌理痕迹。

学生在学习单上写一句：“我发现印痕和画线不同的地方是……”这句话作为入场证据。

### （二）摸一摸纸材：先猜再验证

每组选择三种纸，先摸一摸、看一看，再预测哪一种纸更可能留下明显印痕。教师提醒学生不要只按颜色分类，而要说出粗糙、细密、凸起、吸水、光滑等理由。

本环节不急着印，至少留下一个纸材预测句。

### （三）变一变纸材：制造可印肌理

教师示范刻、剪、撕、揉、卷、折或拼贴中的一两种方法，只示范关键动作，不完整包办作品。学生选择一种方法改造小纸片，并说明“我用……方法让纸出现了……肌理”。

如果学生做成普通手工装饰，教师把问题拉回印痕：“这个地方印出来会留下线、点，还是一片灰？”

### （四）第一次试印：圈出最有证据的一处

教师示范少量上色、均匀压印、慢慢揭纸。学生只做小块试印，不急着完成作品。试印后先圈出最清楚或最有层次的一处，再写一句调整计划。

如果出现糊印，教师不判失败，而是让学生找原因：颜料多了、压力不均，还是揭纸太快。

### （五）比较印法并完成作品

教师出示同版不同印法对照，引导学生比较清楚、模糊、灰层、边缘和肌理保留。学生选择一到两种方法完成小幅作品，并保留最能说明纸材或印法来源的一处印痕。

### （六）展评收束

展评时，作品和试印记录一起上墙。介绍必须说清三件事：用了什么纸材，试了什么印法，留下了什么印痕。同伴评价也要先找证据，再说建议。

## 四、评价证据

| 证据 | 用途 |
| --- | --- |
| 入场观察句 | 判断是否看到印痕特征 |
| 纸材预测句 | 判断是否能根据肌理预测 |
| 改造小样 | 判断是否制造了可印肌理 |
| 试印记录 | 判断是否会试、会看、会改 |
| 作品说明 | 判断是否能用证据介绍纸印作品 |
